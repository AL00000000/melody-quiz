# local_audio/

ここに置いた音源は **このPCでだけ** 使われ、git にも公開用ビルドにも含まれません。

| ファイル名 | 曲 | 置く理由 |
|---|---|---|
| daiseikyou.mp3 | 大盛況（ファミリーマート入店音） | 作曲の著作権が存続（個人利用のみ） |
| kenmai.mp3 | 剣の舞 | 同上 |
| douke.mp3 | 道化師のギャロップ | 同上 |
| trumpetholiday.mp3 | トランペット吹きの休日 | 同上 |
| ningyou.mp3 | 人形の夢と目覚め | 自由ライセンスの録音・楽譜データが見つからなかった |
| csikos.mp3 | クシコス・ポスト | 同上 |

- 有名な部分が頭から始まるファイルにするか、songs.json のその曲の `start`（秒）を書き換えてください。
- 置いたら設定画面の「個人用の曲も出題する」にチェック（著作権存続曲の場合）。
- 自分で購入・録音したものなど、私的利用の範囲で用意してください。
